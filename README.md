# Front-end Sandbox

Песочница и **портфолио фронтенд-проектов**: небольшие законченные демо с явным стеком, Docker Compose (где уместно) и README по каждому подпроекту. Фокус — осмысленные границы задачи, читаемая архитектура и воспроизводимый локальный запуск, в духе инженерных репозиториев с бэкендом и data pipelines.

Цель репозитория: накопить витрину навыков от **чистой веб-базы** (HTML/CSS/HTTP) до **React** и интеграций с API — без раздувания каждого примера до «второго продукта».

## Проекты

Краткий список — ссылки ведут в каталог подпроекта и его README.

### [leads-desk](leads-desk/)

Минимальный **inbound lead intake** (домен «лиды»): форма, таблица входящих, карточка лида, немного `fetch` для JSON. Статика за **nginx**, контрактное API на **WireMock**, подъём одной командой **Docker Compose**. Демонстрирует same-origin доступ к `/api` через reverse proxy и честно документирует ограничения статических моков.

**Стек:** HTML5, CSS3, vanilla JavaScript, nginx, WireMock, Docker Compose.

## Как пользоваться репозиторием

Каждый проект живёт в **своей подпапке** и описан в собственном `README.md` (запуск, стек, сценарий). В корне этот файл остаётся **индексом портфолио**: по мере появления новых демо добавляйте строки в раздел «Проекты» выше.
